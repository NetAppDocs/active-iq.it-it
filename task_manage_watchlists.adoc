= Gestisci una watchlist in Digital Advisor
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
È possibile visualizzare la dashboard per diverse liste di controllo, modificare i dettagli di una lista di controllo esistente ed eliminare una lista di controllo.

.Fasi
. Nel riquadro a sinistra, seleziona *Watchlists*.
+
Viene visualizzata la schermata *Manage Watchlist* (Gestisci lista di controllo).

. Seleziona il nome della watchlist per visualizzare i dettagli della dashboard della watchlist.
. Seleziona *Modifica* per aggiornare i dettagli della watchlist.
. Seleziona *Elimina* per eliminare la watchlist.
