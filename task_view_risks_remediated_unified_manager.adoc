= Visualizza i rischi per le azioni in Digital Advisor e mitigali utilizzando Unified Manager o Ansible Playbook
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Puoi analizzare il tuo sistema di storage visualizzando le azioni e i rischi e mitigarli utilizzando Active IQ Unified Manager o il manuale Ansible.

video::XusFvXM7h-E[youtube,width=848,height=480]
.Fasi
. Seleziona *Visualizza tutte le azioni* nella dashboard.
. Seleziona *Azioni* per visualizzare i rischi associati alle azioni, seleziona *Rischi* per visualizzare tutti i rischi oppure seleziona *Sistemi interessati* per visualizzare i sistemi che richiedono attenzione.
+
Se il rischio può essere mitigato utilizzando Active IQ Unified Manager, il image:spanner.png["Chiave"] Viene evidenziata e se il rischio può essere mitigato utilizzando Ansible Playbook, il image:update_ansible.png["Aggiorna Ansible"] viene evidenziata.



[cols="50,50"]
|===
| Per ridurre i rischi con Unified Manager | Ridurre i rischi utilizzando Ansible Playbook 


 a| 
. Seleziona l'icona image:spanner.png["Chiave"].
. Seleziona *Fix It* per avviare Active IQ Unified Manager.
. Seleziona *Installa* per installare Active IQ Unified Manager 9.7 o versioni successive per usare l'opzione *Fix It*.
. Seleziona *Aggiorna* per passare ad Active IQ Unified Manager 9.7 o versioni successive per usare l'opzione *Risolvi*.

 a| 
. Seleziona l'icona image:update_ansible.png["Aggiorna Ansible"].
. Seleziona *Download* per scaricare il pacchetto di automazione Ansible del firmware AFF e FAS.


|===

NOTE: Per utilizzare l'opzione *Correggi* e le funzionalità del manuale Ansible, è necessario un contratto SupportEdge Advisor o SupportEdge Expert.
